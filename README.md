# RAG-dcomp

### Repositório para projeto da disciplina de Fundamentos de Inteligência Artificial T05 - 2026
O trabalho em questão realiza o benchmark em uma LLM, modelo: openai/gpt-oss-120b acessada via API GropCloud, 
analisando taxas de alucinação e tempo de resposta do modelo com e sem abordagem RAG, usando como banco de dados
o Repositório Institucional da UFS, mais especificamente, as dissertações do Programa de pós-graduação de Ciência da Computação (PROCC).
